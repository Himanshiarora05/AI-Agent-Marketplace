# On-Site Engagement Audit Skill

## When to use
Use this skill to identify user-retention and readability problems on website landing pages. It evaluates the clarity of the brand's above-the-fold value proposition (orientation), the accessibility of navigation paths for deep-linked visitors (context retention), readability barriers (like walls of text), and presence of clear call-to-actions.

## Inputs
* `url` (string): The full absolute URL of the website to audit.
* `technical` (optional path): Technical audit JSON whose bounded `crawl_scope.crawled_urls` are used as representative landing pages.
* `pages` (optional): Explicit same-domain representative URLs.
* `max-pages` (optional integer): Hard page budget, capped at 6.

## Procedure
1. Locate the packaged script [check_engagement.py](scripts/check_engagement.py).
2. Execute the script with the input URL. When a technical audit is available, pass it with `--technical` so engagement is evaluated across representative deep links:
   ```bash
   python skills/engagement-audit/scripts/check_engagement.py <url> --technical tech_findings.json --max-pages 6 --output engagement_findings.json
   ```
3. Read the generated `engagement_findings.json` to inspect:
   * `h1_audit`: Details on H1 heading presence, size, and content.
   * `readability`: Check if there are unformatted "walls of text" paragraphs.
   * `navigation_cta`: Evaluates nav menus, footers, and call-to-action counts/intents.
   * `answerability`: Measures core question coverage and quote-readiness.
   * `deep_link_context`: Measures whether a direct AI citation landing retains context and offers onward paths.
   * `clutter`: Examines code-to-text density.
4. **Evaluate Value Proposition Clarity**:
   * Inspect the actual `h1_text` extracted. Does it state clearly what the site does, or is it vague boilerplate?
   * If it is vague (e.g. "Together we achieve more"), raise a finding for **Vague Value Hook / Weak Orientation**.
5. **Evaluate Context Retention**:
   * Inspect navigation counts. If a deep link has no main nav menu or header, visitors who arrive via AI citations cannot navigate and will bounce.
6. **Compile findings**:
   * If H1 is missing or multiple H1s dilute the core theme, create a finding for **Heading Hierarchy Issue** (severity: `medium` to `high`).
   * If H1 is vague or un-informative, create a finding for **Weak Orientation / Value Hook** (severity: `medium`).
   * If there are walls of text (>100 words) without bullet points, create a finding for **Readability Barriers / Wall of Text** (severity: `medium`).
   * If there are no navigation elements or footer, create a finding for **No Navigation Structure** (severity: `high`).
   * If no CTA buttons are present, create a finding for **Missing Call-to-Action (Dead End)** (severity: `medium`).
   * For each finding, provide the exact `evidence` generated by the script or text analysis, and define a clear, mechanism-sound `suggested_action` (such as "Re-write H1 to be a concrete, descriptive statement of service", "Insert a bold primary Call-to-Action button above the fold", or "Split long paragraphs into 2-3 sentence blocks or bullet points").

## Output
An array of findings following the required schema, for example:
```json
[
  {
    "id": "ENGAGE-001",
    "title": "Missing Heading (H1) on Landing Page",
    "severity": "high",
    "evidence": "Found 0 H1 tags. Missing core heading on the landing page, which hurts above-the-fold orientation.",
    "suggested_action": {
      "summary": "Add a single H1 heading above the fold containing a clear, descriptive value proposition.",
      "priority": "high"
    }
  }
]
```
If no issues are found, return an empty list.

## Multi-page generalization

Do not infer that homepage health represents the whole site. When representative URLs are supplied, analyze each page independently and preserve affected URLs.
